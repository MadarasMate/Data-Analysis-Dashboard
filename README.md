An interactive Power BI report and SQL analysis analyzing customer churn patterns and monthly revenue impact for a telecom dataset.

---

## 📌 Project Summary

The primary objective of this project is to identify high-risk customer segments, quantify financial impact, and provide actionable insights for customer retention strategies.

### 🔍 Key Findings:
1. **Contract Type:** Customers on Month-to-month contracts have the highest churn rate (~42%), while 2-year contract customers rarely churn (<3%).
2. **Internet Service:** Users with Fiber Optic connections churn significantly more than DSL users.
3. **Customer Tenure:** Most churn happens within the first 12 months of tenure.
